# Local SAM-FS packages: film → produksjon

Put complete packages from SAM-FS → film → produksjon here, keeping each
package's original directory name and internal structure. Package archives
can also be placed here.

Metadata-only copies are also supported. Record which files were omitted in
the corresponding example notes under `examples/sam-fs/`; a local copy does
not have to contain the complete media payload to support mapping work.

Everything in this directory except this README is ignored by Git, including
media, metadata, archives, and extracted working files.

Once packages are available, we can inspect these local copies and copy the
useful small metadata, manifests, and checksum files into
[examples/sam-fs/](../examples/sam-fs/README.md). Include a directory listing
with file sizes and notes on the original SAM-FS path, capture date, and
omitted content with each extracted example. Keep the complete source copies
intact here for further inspection and testing.
